# Oona DV 1.0.0

An independently maintained IINA fork with embedded Dolby Vision rendering.
This is not an official IINA release or a Dolby-certified player.

## Changes

- Play tested Dolby Vision Profile 5 HEVC content with correct SDR colors using
  the pinned mpv OpenGL-next/libplacebo renderer inside the existing IINA window.
- Remove the earlier separate-window and nested-run-loop experiments.
- Fix CoreAudio channel layout initialization, subtitle orientation and screenshot
  rendering in the custom mpv backend.
- Default the arrow buttons to exact backward/forward 10-second jumps, with
  matching icons, preserving playback speed and pause state.

## Download and compatibility

- Apple Silicon only. This package requires macOS 27.0.1 or newer; runtime validation
  was performed on macOS 27.0.1 only. Intel and other macOS versions are unverified.
- Ad-hoc signed, not Developer ID signed or notarized. macOS may require explicit
  approval in Privacy & Security after an attempted launch.
- Mount the DMG and drag Oona DV.app into Applications. It uses its own preferences
  and bundle identifier, separate from IINA and the development test application.
- SDR output is the default; HDR can be enabled manually but is not validated.
  SDR conversion for the tested Profile 5 sample is verified. Profile 7 FEL,
  Profile 8, HDMI Dolby Vision signaling and HDR/EDR display accuracy are not
  claimed. Screenshots currently use 8-bit SDR; custom mpv ICC profiles are ignored.

## Validation

The user accepted playback, audio, subtitle orientation and 10-second button
behavior. A full Xcode Release build and bundle signature verification passed.
Automated integration checks covered CoreAudio output, pause/resume, exact seeks,
screenshots, and DV/SDR transitions. An offscreen framebuffer test covered subtitle
orientation with letterboxing. This does not replace broad clean-machine testing.
